# DreamPlayer 中文默认、本地化与刮削可靠性 PRD

## 1. 目标

修复 Android 实机上 TMDB 中文片名无法自动匹配、`danmu_api` 正常弹幕响应被误判、WebDAV“继续观看”恢复后丢失认证的问题，并为整个 Flutter 界面建立中文/英文双语言能力。首次安装和未明确选择语言时默认中文，用户可在设置中切换英文。

## 2. 范围

- TMDB 搜索同时使用本地化标题和原始标题评分，中文片名可匹配英文展示名条目。
- TMDB 请求语言跟随应用语言；中文使用 `zh-CN`，英文使用 `en-US`。
- TMDB 网络、鉴权和无匹配状态不再被静默吞掉，关键交互提供可理解的错误。
- `danmu_api /comment` 同时兼容带 `success` 信封和仅含 `comments/count/videoDuration` 的裸响应。
- WebDAV 继续观看记录保留 `webdavServerId` 等非敏感来源信息，并在恢复播放前从原生安全存储重新取得认证头。
- Flutter 应用提供中文、英文两种语言，默认中文；设置页提供持久化语言切换。
- 所有主要用户界面、对话框、按钮、空状态、错误与播放设置均通过统一本地化层输出；媒体标题、服务器名称、路径、协议名和第三方固有名词不翻译。

## 3. 架构

### 3.1 本地化

- `AppLocaleController` 是应用语言的单一事实来源，负责从 `SharedPreferences` 读取和保存 `zh`/`en`。
- `MaterialApp.locale` 由控制器驱动，并注册 Flutter Material/Cupertino 本地化代理。
- 应用文案集中在本地化资源层；界面不得自行判断语言。
- 未命中的动态媒体文本保持原文，避免翻译文件名、片名或服务端内容。

### 3.2 TMDB

- `TmdApi` 从应用语言设置得到请求语言。
- `_score` 与 `_queryScore` 对 `title`、`originalTitle` 分别评分并取最大值。
- 本地化标题为空时回退原始标题；搜索结果仍以 TMDB 本地化标题展示。
- 网络失败、401/429 和无匹配属于不同状态，不能统一折叠为 `null` 后无限加载。

### 3.3 弹幕

- 明确的 `success == false` 仍视为协议错误。
- `success` 缺失且 `comments` 为列表时视为有效兼容响应。
- `comments` 缺失或类型错误仍失败，避免把服务端错误页缓存为空弹幕。

### 3.4 WebDAV 继续观看

- 普通偏好设置只保存服务器 ID、URI 和播放元数据，不重复保存 Authorization 密钥。
- 恢复时使用 `webdavServerId` 调用原生 WebDAV 通道，从加密存储重新取得 Authorization。
- 兼容历史记录：可从 `resumeKey` 推导服务器 ID 时尝试修复；无法恢复时给出明确提示。

## 4. 用户流程

1. 应用首次启动进入中文界面。
2. 用户可在“设置 → 语言”选择中文或 English，选择立即生效并持久化。
3. 中文文件名搜索 TMDB 时可通过 `original_name/original_title` 命中，随后加载海报、详情和剧集。
4. 播放匹配剧集时，弹幕源的裸评论响应被解析、缓存并显示。
5. 从首页“继续观看”恢复 WebDAV 视频时重新取得认证信息，不再返回 HTTP 401。

- 中文模式下 TMDB 使用 `zh-CN`，英文模式下使用 `en-US`。
- 实际弹幕源对该视频返回的 7863 条裸响应可正常解析，不再显示“加载失败”。
- WebDAV 继续观看恢复日志不再出现 `webdavServerId=null`，播放请求带有效认证。
- 新安装默认中文；设置中可切换英文并在重启后保留。
- 中文模式下主要界面不存在遗留的英文操作文案。
- 不记录 TMDB Key、弹幕 Token、WebDAV Authorization 或带凭据 URL。
- `flutter analyze`、完整 Flutter 测试及 Android 构建通过。
- 在一加 PJD110 上验证首页 TMDB、剧集详情、单集弹幕、整季弹幕和 WebDAV 继续观看。
